# Dokumentation

Denna mapp samlar Team 2:s gemensamma dokumentation för applikationen och
Workshop 3.

## Innehåll

- [product_backlog.md](product_backlog.md): gemensam status för risker,
  förbättringsarbete och kursmoment.
- [workshop3_setup_status.md](workshop3_setup_status.md): teknisk setup,
  verifieringar och kvarvarande uppföljning.
- [team_work_summary_2026-09-21.md](team_work_summary_2026-09-21.md):
  sammanfattning av dagens gemensamma arbete.

## Rutin

- GitHub Issues används för det dagliga arbetet.
- Backlogfilen ger utbildaren och gruppen en samlad översikt.
- Status sätts till `Done` först efter merge och verifiering.
- Säkerhetsfynd dokumenteras defensivt utan fungerande angreppsinstruktioner,
  hemligheter eller skarpa flaggvärden.
